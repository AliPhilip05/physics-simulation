# Session — October 30, 2026

## Week 7: 3D numerical validation

Added center-of-mass offset and total-momentum diagnostics to the 3D particle
cloud. Added a common-time timestep study at `t/t0 = 0.2`. Three integrations
use `dt = 0.004`, `0.002`, and `0.001`; a run with `dt = 0.00025` supplies the
RMS-radius reference at the same time. The 3D HUD displays RMS-radius error and
absolute total-energy error for each timestep.

The cloud remains 64 equal-mass particles in a cold, centered uniform sphere.
The direct pair force and the total-energy diagnostic use the same fixed
Plummer-softened potential with `epsilon = 0.05 R0`. These results measure
integration error for this finite-N softened model; they are not a convergence
study in particle number or softening length, and they do not validate a fluid
star.

## Common-time results

| Timestep | RMS-radius error against `dt = 0.00025` | Absolute energy error |
| ---: | ---: | ---: |
| 0.004 | 4.544668941175e-8 | 4.350411108023e-7 |
| 0.002 | 1.122828685585e-8 | 1.087674764699e-7 |
| 0.001 | 2.673418042498e-9 | 2.719231873005e-8 |

Both diagnostics improve by about a factor of four per timestep halving,
consistent with second-order velocity Verlet over this short interval.
