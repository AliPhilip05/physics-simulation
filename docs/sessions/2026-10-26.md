# Session — October 26, 2026

## Two-week code checkpoint

Added code for the spherical-shell and numerical-validation milestones. The
model now tracks 16 ordered material boundaries. Their initial radii are
evenly spaced from 1/16 to 1, and their fixed enclosed masses are `r0^3`, which
represents uniform initial density with total normalized mass 1. The
pressureless, spherical, Newtonian assumptions and normalized units remain in
force: `G = M_total = R_initial = 1`, with time measured in
`t0 = sqrt(R_initial^3 / (G M_total))`.

Each boundary advances with velocity Verlet using its fixed enclosed mass.
Candidate boundaries and elapsed time are committed together. The step rejects
invalid state, shell crossing, non-finite results, and a surface at or below
the numerical cutoff `R/R0 = 0.25`. The cutoff remains a numerical integration
limit, not a horizon calculation. Shell state and trajectory history are
encapsulated behind read-only accessors.

The window draws the concentric boundaries and a surface-radius versus model
time plot. The plot overlays the analytic pressureless uniform-sphere solution,
whose normalized free-fall time is `pi / sqrt(8) = 1.110720734540`. A built-in
common-time comparison displays absolute surface-radius error at `t/t0 = 0.5`.

## Numerical comparison

An independent calculation of the surface velocity-Verlet trajectory gives:

| Timestep | Numerical surface radius at `t/t0 = 0.5` | Analytic radius | Absolute error |
| ---: | ---: | ---: | ---: |
| 0.01 | 0.869251508497 | 0.869248697576 | 2.810920831542e-6 |
| 0.005 | 0.869249400362 | 0.869248697576 | 7.027860032816e-7 |
| 0.0025 | 0.869248873276 | 0.869248697576 | 1.756999887803e-7 |

Halving the timestep reduces the radius error by approximately four, consistent
with the second-order velocity-Verlet method. The comparison occurs before the
surface reaches the numerical cutoff.

## Spatial 3D extension

Added a selectable, direct-summation Newtonian N-body mode. It starts with 64
equal-mass particles in a deterministic, centrally symmetric sample of a
uniform unit sphere, all initially at rest. State uses three-component `f64`
positions and velocities. Pair forces are accumulated once per pair and applied
with equal and opposite signs. Velocity Verlet advances all particles together.

The pair force and potential use fixed Plummer softening
`epsilon = 0.05 R0`; the displayed total-energy error is measured against that
softened potential. The scene uses Macroquad's perspective camera, particles,
axes, and grid. The 3D mode is the default; key `2` selects the spherical-shell
model and key `3` resets to the 3D model.

This is the project's first spatial 3D calculation, not a three-dimensional
fluid or relativistic star. Finite particle number and force softening affect
the result. The new tests and runtime window have not been reviewed yet. Next,
run the suite, record energy drift as the timestep changes, and inspect the
perspective scene and the 2D/3D mode switches.
