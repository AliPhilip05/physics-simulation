# Session — October 30, 2026 (Week 8)

## Week 8: symmetry breaking in the 3D particle model

Added an oblate initial condition using the same 64 equal-mass sample points,
with x and y contracted before the whole cloud is rescaled to outer radius
`R0 = 1`. The cloud stays centered, cold, and Newtonian. Pairwise gravity,
Plummer softening, total mass, particle count, and the integration method remain
the same. Initial total energy is recalculated for the altered geometry.

Press `A` in 3D mode to switch between the spherical and oblate starts. The
display reports RMS extents along the fixed coordinate axes and the current
minor-to-major RMS extent ratio. These are coordinate-axis diagnostics; they
are not principal axes for a cloud whose figure is rotated. Press `R` to reset
the currently selected shape. The README needs the new `A` control and this
shape diagnostic explained in the user's words.
